# Red-team checklist (run before changing any key judgment)

The reviewer is not an advocate for the current judgments. It applies the checks below as a
filter against confirmation bias; a claim that fails gets a PARTIAL/WEAK marker regardless of
the source's authority.

## A. Six evidence axioms — grade each proposed change PASS / PARTIAL / WEAK / FAIL

| # | Axiom | Question |
|---|---|---|
| A1 | Sufficient | Is the evidence volume/quality proportional to the weight of the change? |
| A2 | Consistent | Does it contradict anything already in the report? If so, is the contradiction addressed? |
| A3 | Falsifiable | What specific observation would refute it? Is that an indicator? |
| A4 | Independently corroborated | ≥2 independent primaries — not paraphrases of one wire? |
| A5 | Non-circular | Does the claim rest on the report's own earlier inference? |
| A6 | Alternatives considered | Were competing hypotheses re-scored in the ACH matrix? |

Aggregate: STRONG (≥5 PASS) → change allowed; MODERATE (3–4) → change allowed at one level
lower confidence than proposed; WEAK (<3) → log as lead, no change.

## B. Bias sweep — answer each in one line

- **Anchoring**: is the first-reported framing still driving the judgments?
- **Confirmation**: did the sweep only search terms that would confirm the leading hypothesis?
- **Echo chamber**: do "multiple sources" all consume the same original? (trace the chain)
- **Authority**: is a claim graded higher because of who repeated it rather than who originated it?
- **Availability**: is loud commentary crowding out quiet primary evidence (registries, archives)?
- **Sunk cost**: is a hypothesis kept alive because the report has invested sections in it?

## C. Adversarial questions

1. What is the single strongest argument that the top hypothesis is wrong?
2. Which judgment would collapse if one specific source turned out to be wrong? Name the source.
3. What did we *not* search that a hostile reviewer would search first?
4. Is any "negative result" actually a coverage gap (wrong URL pattern, un-archived path)?
